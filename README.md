# Orgchart - VisuallyJs Angular

An organization chart, or orgchart, is a diagram that shows the structure of an organization and the relationships and relative ranks of its parts and positions/jobs. It provides a clear visual representation of a company's hierarchy, helping employees understand reporting lines and organizational roles.

This is an org chart you can use as a base to build your own org charts. It contains examples of how to:

- configure a zoomable and pannable canvas
- render nodes
- configure the appearance and event bindings for edges
- add a miniview component
- add a controls component, providing a zoom to extents button
- add an inspector
- zoom in on a specific vertex in the dataset

https://visuallyjs.com/demonstrations/orgchart
